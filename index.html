Tube definition

Triodes use the Koren equation: Ip = (E1^EX)/KG1 where E1 = (Vp/KP)·ln(1 + exp(KP·(1/MU + Vg/√(KVB+Vp²)))). Edit the JSON; type:"traced" uses sampled curves instead.

Amp library

Each entry is a full amp signal chain. Click one to see every stage; load it into Designer or save your own from the Designer tab.

Hardware Out

The current operating-point solution is broadcast as JSON over Web Serial. On the amp, an MCU receives this and drives digital pots / relay-switched RC banks to set Rp, Rk, Cc, Ck, and B+ regulation target. The same JSON is what gets baked into a preset — so a preset really is "the operating point of this tube in this topology", which is exactly the contract you'd want for an analog modelling amp.

Suggested MCU contract

// Newline-delimited JSON over USB CDC, 115200 8N1
{
  "tube":"12AX7", "topo":"cc-cb",
  "bplus":300,         // volts, regulated target
  "rp":   100000,      // ohms, plate resistor (digipot or relay matrix)
  "rk":   1500,        // ohms, cathode resistor
  "cc":   22e-9,       // farads, coupling cap (switched bank)
  "ck":   22e-6,       // farads, cathode bypass cap
  "rl":   470000       // ohms, next-stage grid leak (informational)
}
